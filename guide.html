📍 Vị trí

Menu ☰ → dòng "Tự lưu OCR: BẬT/TẮT" (nằm giữa "Chế độ tối" và "Backup & Cloud")

✅ Khi BẬT — tự lưu khi TẤT CẢ điều kiện sau đúng

  • Mode OCR sạch — không đoán số (không có +fix)
  • Confidence ≥85% — không có dải vàng/đỏ
  • Tổng OCR khớp 100% với "Tổng N đơn hàng"
  • Phân bố hợp lý — dải 0-2 chiếm ≥50%
  • Nhận diện được tab (Giao/Lấy/Hoàn)
  • Đọc được ngày trên ảnh

⏸️ Khi TẮT

Mọi case đều mở modal — user tự check và lưu tay.

⚠️ VẪN MỞ MODAL dù toggle BẬT

  • App phải đoán số để khớp tổng (mode +fix)
  • Có dải vàng (conf 70-84%)
  • Tổng lệch — không khớp "Tổng N đơn hàng"
  • Phân bố bất thường — dải 0-2 <50%
  • Không detect được tab hoặc không thấy ngày

Bấm "Lưu cấu hình tháng này" để lưu.

⚡ RULE QUAN TRỌNG — Phụ cấp Tài xế

Tài xế chỉ được cộng vào lương khi Đơn Giao ≥ 1.500/tháng.

• < 1.500 → không cộng (bỏ qua ô Tài xế)

• ≥ 1.500 → cộng đầy đủ

→ App hiện banner cảnh báo ngay dưới ô nhập, báo còn thiếu bao nhiêu đơn.

📐 Công thức

Lương 1 công = (LCB + Bưu cục + Tài xế) / ngày tối đa

Ngày tối đa:
  • Tháng 2  → 24 ngày
  • Tháng khác → 26 ngày

Số công = đếm ngày có:
  Giao + (Lấy / 6) + Hoàn ≥ ngưỡng
  • Miền:   ≥60 = 1 công, ≥30 = 0.5 công
  • HCM/HN: ≥80 = 1 công, ≥40 = 0.5 công

Tích lũy = Lương 1 công × số công
📅 Lưu theo tháng

Lương + Hạng lưu riêng theo từng tháng. Đổi tháng → tự chuyển cấu hình tháng đó.

Riêng Khu vực (Miền / HCM-HN) chọn 1 lần, áp dụng mọi tháng.

💾 Dữ liệu & Backup 4 mục
💾 TẠI SAO CẦN

Xóa cache trình duyệt / reset máy → mất data. Cloud backup giúp khôi phục lại.

🔑 Setup 1 lần (5 phút)

  1. Vào github.com/settings/tokens (đăng nhập GitHub)
  2. Bấm Generate new token (classic)
  3. Note: spx-backup · Expiration: No expiration
  4. Scope: tích gist → bấm Generate
  5. Copy token ghp_...
  6. Mở app → Menu ☰ → Backup & Cloud → dán token
  7. Bấm 🔌 Kiểm tra → ☁️ Backup (tạo Gist lần đầu)
  8. Tích "Tự động backup" → từ đó tự sync mỗi thay đổi

🔄 Khôi phục khi mất data

  1. Menu ☰ → Backup & Cloud
  2. Bấm ⬇️ Khôi phục từ Cloud
  3. Chọn GHI ĐÈ (xóa hết cũ) hoặc THÊM VÀO (giữ cũ + thêm mới)

📁 Backup file JSON (offline)

  • 💾 Lưu file — tải file về máy
  • 📥 Nạp file — chọn file JSON đã lưu
  • 🔄 Phục hồi tự động — khôi phục từ vault (bản sao lưu ngầm)

⏰ Cách hoạt động

  • Sau 7 ngày kể từ lần backup gần nhất
  • Mở app → đợi 5 giây → hiện dialog hỏi
  • Bấm "📥 Lưu file ngay" → tải file về Downloads
  • Bấm "Để sau" → mai mở app sẽ hỏi lại

💾 Cache là gì?

App lưu kết quả OCR của mỗi ảnh trong IndexedDB (8MB, không giới hạn như localStorage). Ảnh quét lại → trả kết quả cache, không OCR lại → nhanh hơn.

🗑️ Khi nào cần xóa cache?

  • Test lại ảnh đã quét — bắt buộc xóa để app chạy OCR mới
  • Nghi kết quả bị "kẹt" từ lần quét trước
  • Sau khi update version mới
